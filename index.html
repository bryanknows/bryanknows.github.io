Approach

How I decide what to build

  • Map it before touching itI sit with the people doing the work and write down every step, including the workarounds nobody mentions.
  • Automate, redesign, or leave itSome steps should disappear, some need a better process, and some are fine done by hand.
  • People approve what residents seeAnything that touches a listing, an applicant, or a tenant message gets a human check before it goes out.
  • Built for the next personEvery tool ships with a plain-language SOP so the team can run and fix it without me.
